# 📸➡️📄 Image to PDF Converter

Ek simple aur fast **Image to PDF Converter Tool** jo sirf **HTML, CSS aur JavaScript** se bana hai.  
Is tool ki madad se aap apni images ko select karke unhe ek single PDF me convert kar sakte ho.  

---

## 🚀 Live Demo
👉 [Click here to try the tool](https://sudheer829940.github.io/image-to-pdf)  

---

## 📌 Features
- Multiple images upload karne ki facility  
- Drag & Drop support (agar code me add hai)  
- Automatic image preview  
- Convert all images into **PDF** in one click  
- One-click **Download PDF** option  

---

## 📂 How to Run Locally
1. Repository clone karo ya ZIP download karo.  
2. `index.html` file ko kisi browser me open karo.  
3. Apni images upload karo → Convert to PDF button dabao → PDF download kar lo.  

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**  
- (Optional: `jsPDF` library agar tumne use ki hai)
